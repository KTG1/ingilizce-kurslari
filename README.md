# İngilizce Kursları — şehir sayfası şablonu

Şehir bazlı İngilizce kursu landing page şablonu. Next.js App Router kullanır.

## Geliştirme

```bash
npm install
npm run dev
```

`/istanbul`, `/ankara` ve `/izmir` hazır örneklerdir. Yeni bir şehir için `lib/cities.ts` dosyasına veri ekleyebilir veya doğrudan `/{sehir-slug}` adresini kullanabilirsiniz.
